# 381 — Implementation and validation

## Implementation
- New `src/modules/strategy-data-recommendations/tactical-knowledge-pack.js`: bundle-lexical `const TacticalKnowledgePack` (same pattern as `CurrentActionHintEngine`), no dependencies on other modules. Host capabilities: `GM_xmlhttpRequest`, `localStorage`. State machine: sync cache read at init → at most one anonymous GET per page load when absent/expired/invalid → validated in-memory state only; `get()` is synchronous, read-only, expiry-gated.
- Registry seam (`active-preset-registry.js`): pure `knowledgeAssessment({preset, situation, context})` reusing the existing alias resolver; rejects non-active presets; maps pack conditions onto the runtime context (approximate where documented); seed match → +3 non-stacking, clamped ±5, `evidenceDelta` dormant at 0; returns `{delta, source:'seed'|'none', ruleIds, n:null, packVersion}`. `evidenceAdjustment` becomes an adapter returning `assessment.delta` (catch-all → 0, finite guaranteed). The registry tolerates the pack module being absent (bare test sandboxes).
- UI provenance (`strategy-data-task-a-ui-extension.js`, minimal): one escaped line under the compact-coach heading for the DISPLAYED preset (`ruleDecision.finalTactic.presetId` when the merged block renders with a preset base, else `resolveRecommendedPresetName`): `База: seed (гипотеза)` on a matched seed, else `База: нет совпавших данных`. Primary provenance source is the displayed candidate's own `parts.boundedEvidenceAdjustment` (same-decision data — the adjustment the direction policy actually applied); a live `registry.knowledgeAssessment` on the raw `moment.context` runs ONLY when candidate parts are unavailable. That fallback can only UNDER-report, never over-report: the raw context's `underPressure` is a subset of the normalized context's (signal-derived normalization can only add pressure), so the fallback never fabricates a seed label the policy did not apply. For v11 suite decisions the fallback is unreachable — candidates always carry `parts`. Unavailable attribution renders the none-variant; no re-fetch, no re-render on fetch completion; margin confidence display untouched.
- Registration: `bundle-order.json` (file entry between coach-hint-snapshot-context-layer and the registry, `expectedModuleCount` 92, audit record, registry `requires` entry) and one `ACTIVE_MANUAL_BOUNDARY` symbol record in `data/audit/manual-match-symbol-review-v1.json` (allowedFiles = pack loader + registry only).
- CI: `runtime-tactics` job gains `node --check` of the new module and `node tools/test-tactical-knowledge-pack.mjs` beside the existing runtime tests (test file authored by the follow-up test worker).
